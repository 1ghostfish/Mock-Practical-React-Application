# Saltwater Kitchen Recipe Database

You are building the database for **Saltwater Kitchen**, a recipe app for a small Devon cookbook publisher, using Prisma and PostgreSQL.

## Start here

Your **task sheet is the printed handout**. It explains the scenario, what to build and what to hand in, and each task gives you less help than the one before. Work from the paper copy and type the code in yourself.

The files in this project you will need:

1. **[docs/setup.md](docs/setup.md)**: check the packages are installed, start the database and make your `.env` file. Do steps 1 to 3 only. There is no internet in this session, so do not run `npm install`.
2. **[docs/sample-data.md](docs/sample-data.md)**: the chefs, cookbooks, recipes, nutrition labels and ingredients to use in your seed script. The same data is at the back of the printed sheet.
3. **[docs/design-report.docx](docs/design-report.docx)**: the Word document for your design report. Open it in Word and write your answers in the boxes, at the end or as soon as you get stuck.

The session is 2 hours. Spend about 1 hour 30 minutes building, then **stop at 1:30 and spend the last 30 minutes on the report**, even if you have not finished building. The task sheet has a suggested time for each task.

## What you will hand in

| Deliverable           | Where it goes          |
| --------------------- | ---------------------- |
| Database schema       | `prisma/schema.prisma` |
| Migrations            | `prisma/migrations/`   |
| Seed script           | `prisma/seed.ts`       |
| Design report, with your ERD screenshot pasted in | `docs/design-report.docx` |

Full details are on the printed task sheet.
